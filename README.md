# Verify AI Summaries for Accuracy

This example demonstrates how AI-generated summaries can contain factual errors or omissions. It simulates an AI summary with intentional inaccuracies and then provides a simple verification process to highlight discrepancies against the original text, emphasizing the need for human review and critical thinking.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
